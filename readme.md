## 📄 Sobre o Projeto

Este é o meu portfólio pessoal, desenvolvido para apresentar minha jornada como **Desenvolvedor Full Stack** e estudante de Engenharia de Software. 

O design do projeto reflete minha dupla paixão: **Tecnologia e Música**. A interface combina uma estética moderna (Dark Mode/Glassmorphism) com elementos clássicos de partitura musical.

### ✨ Destaque: "Music Snake" (Background Dinâmico)
O diferencial deste site é a *Hero Section* (cabeçalho), que apresenta uma animação procedural desenvolvida com **HTML5 Canvas** e **JavaScript**. 
* **O Conceito:** Uma releitura do clássico "Snake Game", onde a cobrinha percorre uma partitura musical infinita.
* **A Lógica:** O script roda de forma autônoma (não jogável), utilizando uma IA simples que persegue notas musicais (comida) aleatórias, criando um papel de parede vivo e único a cada visita.

## 🎨 Funcionalidades e Design

* **Animação Canvas:** Renderização em tempo real de elementos gráficos (pauta, clave de sol, notas).
* **Glassmorphism:** As seções de conteúdo utilizam fundos translúcidos com desfoque (`backdrop-filter: blur`), criando uma sensação de profundidade sobre o canvas animado.
* **Responsividade:** Layout adaptável para dispositivos móveis e desktop.
* **Integração:** Links diretos para WhatsApp (API) e outros projetos no GitHub.
